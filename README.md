# Alertas de médias (app)

Tela do monitor de ações para o iPhone. Publicada pelo GitHub Pages.

- Abrir no Safari, tocar em Compartilhar › Adicionar à Tela de Início.
- Em Ajustes, conectar ao repositório privado do monitor com um token (fica só no aparelho).
- Ver com dados de exemplo: abra o endereço com `?demo` no final.

Não há dados pessoais neste repositório: a carteira e os alertas ficam no repositório privado.
