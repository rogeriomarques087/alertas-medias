Médias

    Conexão com o GitHub

    O app lê a carteira e os alertas do repositório onde o monitor roda, e grava lá suas compras e vendas.

    Como criar o token

    No GitHub: Settings › Developer settings › Fine-grained tokens › Generate new token. Em Repository access, escolha só o repositório do monitor. Em Permissions › Contents, marque Read and write. O token fica guardado só neste aparelho.

    Tipo de média

    Use o mesmo do seu gráfico. MME/EMA é exponencial, MMS/SMA é simples.

    Tipo de média

    1. 1

      Adicionar à Tela de Início

      No Safari, toque em Compartilhar e depois em “Adicionar à Tela de Início”. Abra o app pelo ícone que aparecer.

    2. 2

      Ativar notificações

    3. 3

      Ligar ao monitor

      Copie o código e cole no segredo PUSH_SUBSCRIPTION do GitHub. Só precisa fazer uma vez.

    O app só avisa. Comprar ou vender é sempre decisão sua.
